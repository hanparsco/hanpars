本目录收录常见原料药品种。请选择品种并告知质量标准和目标市场，我们将回复合作生产企业的供货方案。

提交询盘

按单采购本栏目所列产品均按订单采购，不备现货，供货情况以询盘确认为准。

如何询盘

先检索清单，再提供药典等级、数量、目标市场以及所需文件：检验报告（CoA）、DMF 或 CEP 编号、GMP 证书。

列入清单仅表示可代为询价，不代表有库存或已在伊朗注册。
